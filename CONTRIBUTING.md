# Contributing to ELEN_GALAXIA

Welcome! This is a personal professional standard, but contributions to the core architecture principles are welcome.

## How to Contribute

1. **Modular MCPs:** If you have an MCP server wrapper that follows the "Hardware-Zero" philosophy, feel free to propose it in the `servers/` directory.
2. **Infrastructure Definitions:** We are moving towards full Terraform/OpenTofu automation. Contributions to the `resources/` directory are highly appreciated.
3. **Documentation:** Clarity is key. If you find the architecture guide confusing, please open an issue or PR.

## Code of Conduct

Maintain a high standard of professional and technical excellence. Focus on performance, security, and portability.
